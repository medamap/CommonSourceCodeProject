- **実装ファイル**: `src/vm/mb8877_compat.cpp` (1203-1252行目)

## 実装仕様詳細

### 1. 機能概要
set_track_size()メソッドは、各ドライブのトラックサイズをカスタマイズ可能にする機能を提供します。非標準フォーマットディスクや特殊なコピープロテクトを持つディスクのエミュレーションに必要です。

### 2. サポートするトラックサイズ範囲
- **最小サイズ**: 1,024バイト
- **最大サイズ**: 65,536バイト
- **標準サイズ**:
  - 2D/2DD: 6,250バイト
  - 2HD: 12,500バイト
  - FM: 3,100バイト（参考値）
  - 2HD alternate: 10,410バイト（参考値）

### 3. 実装内容

#### 入力検証
1. **ドライブ番号検証**
   - 範囲: 0 ～ MAX_DRIVE-1
   - 無効な場合はエラーログを出力して処理を中断

2. **ディスク存在確認**
   - 指定ドライブにディスクが挿入されていることを確認
   - ディスクがない場合はエラーログを出力して処理を中断

3. **サイズ範囲検証**
   - 1,024 ～ 65,536バイトの範囲内であることを確認
   - 範囲外の場合はエラーログを出力して処理を中断

#### トラックサイズ設定
- DISKオブジェクトのtrack_sizeメンバーに直接値を設定
- 設定後、デバッグログで操作内容を記録
- 標準フォーマット（6250/12500バイト）の場合は特別にログ出力

### 4. エラーハンドリング
以下の条件でエラーとなり、トラックサイズは変更されません：
- ドライブ番号が負数または MAX_DRIVE 以上
- 指定ドライブにディスクが挿入されていない
- トラックサイズが 1,024バイト未満
- トラックサイズが 65,536バイトを超える

エラー時は適切なデバッグログメッセージを出力し、既存の設定を保持します。

## 既存機能への影響
- **タイミング計算**: DISKクラスのget_track_size()メソッドが設定値を返すため、タイミング計算に自動的に反映
- **フォーマット処理**: トラックサイズがフォーマット処理で参照される
- **MFM/FM設定との連携**: set_drive_mfm()と独立して動作し、任意の組み合わせが可能

## Phase 12cへの引き継ぎ事項
1. set_drive_type()の実装により、ドライブタイプ別のデフォルトトラックサイズ設定が可能になる
2. トラックサイズ設定がディスクイメージの読み書きに与える影響の検証が必要
3. 特殊フォーマットディスクの実際のテストケース追加を検討

set_track_size()メソッドの実装により、MB8877互換層は様々なディスクフォーマットに対応可能となりました。エラーハンドリングも適切に実装され、無効な入力に対しても安定した動作を保証します。
