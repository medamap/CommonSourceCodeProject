# Write Track実装計画

## 概要
MB8877互換実装で未完成の機能を段階的に実装する計画。最優先事項はWrite Track（フォーマット機能）の実装。

## 実装フェーズ

### Phase 10: Write Track基本実装
- **優先度**: 最高
- **期間**: 1-2日
- **内容**:
  - Write Trackデータ処理の実装
  - フォーマットデータパターンの解析
  - セクタヘッダ/データの書き込み
  - CRC計算と書き込み

### Phase 11: タイミング精度向上
- **優先度**: 高
- **期間**: 1-2日
- **内容**:
  - get_usec_to_start_trans()の正確な実装
  - get_usec_to_next_trans_pos()の実装
  - get_cur_position()の改善
  - ディスク回転シミュレーション

### Phase 12: ドライブ設定機能
- **優先度**: 中
- **期間**: 1日
- **内容**:
  - set_drive_mfm()の実装（FM/MFM切り替え）
  - set_track_size()の実装
  - set_drive_rpm()の実装（必要に応じて）

### Phase 13: MB89311拡張対応
- **優先度**: 低
- **期間**: 1日
- **内容**:
  - cmd_format()のMB89311固有実装
  - 拡張コマンドの完全対応

## テスト計画

### Write Trackテスト
1. 基本的なトラックフォーマット
2. 各種セクタサイズでのフォーマット
3. 不良セクタマーキング
4. 実際のディスクイメージでの検証

### タイミングテスト
1. セクタ間タイミングの検証
2. インデックスホール検出タイミング
3. DRQタイミングの精度測定

- フォーマット機能が正常動作
- 既存のテストケース（72.7%）を維持
- 新規テストケース95%以上合格
