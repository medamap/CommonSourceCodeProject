# 統合テストエージェント指示書

## エージェント名
IntegrationAgent-RealTest

## 作業目的
Phase 2で構築したテストフレームワークを使用してmb8877_compatの統合テストを実施し、実際のmb8877.cppとの置き換えテストを行う

## 前提情報
- Phase 1: mb8877_compat.cpp/h の完全実装済み（約2800行）
- Phase 2: テストフレームワーク構築済み（95+テストケース、一部未完了）
- 残りテスト項目: Type IV、エラーハンドリング、タイミング検証、互換性テスト

## 作業項目

### 1. Phase 2残りテストの完了
#### 1.1 Type IV コマンドテスト
- Force Interrupt (0xDx) の各種条件テスト
- 割り込み条件フラグテスト
- コマンド中断時の状態確認

#### 1.2 エラーハンドリングテスト
- Record Not Found (RNF) エラー
- CRCエラー処理
- Data Lost エラー
- Write Protect エラー
- Not Ready エラー

#### 1.3 タイミング検証テスト
- シーク時間の測定と検証
- DRQタイミングの確認
- セクタ間のタイミング
- インデックスホール検出

### 2. 実際の置き換えテスト
#### 2.1 ファイル置き換え準備
- 元のmb8877.cpp/hのバックアップ作成
- mb8877_compat.cpp/hをmb8877.cpp/hに置き換え
- ビルドエラーの修正

#### 2.2 基本動作確認
- CommonSourceCodeProjectの各エミュレータでのビルド確認
- 基本的な起動テスト
- ディスクアクセスの動作確認

#### 2.3 互換性テスト
- FM7エミュレータでの動作確認
- X1エミュレータでの動作確認
- その他MB8877使用エミュレータでの確認

### 3. 問題の発見と修正
#### 3.1 動作不具合の特定
- 起動しないケースの調査
- 動作異常の詳細ログ取得
- 問題の根本原因分析

#### 3.2 修正実装
- 発見された問題の修正
- テストケースの追加
- 修正後の再テスト

### 4. 性能測定
#### 4.1 パフォーマンステスト
- 元のmb8877.cppとの処理速度比較
- メモリ使用量の比較
- CPU使用率の測定

#### 4.2 ボトルネック分析
- 処理遅延の原因特定
- 最適化ポイントの洗い出し

## 作業手順

1. Phase 2残りテストの実装と実行
2. 元mb8877.cpp/hのバックアップとファイル置き換え
3. ビルドエラーの修正
4. 基本動作確認
5. 各エミュレータでの動作テスト
6. 問題発見時の詳細調査と修正
7. 性能測定と最適化ポイント特定
8. 結果レポートの作成

## 成果物

1. 追加テストコード:
   - test/test_mb8877_type4_commands.cpp
   - test/test_mb8877_error_handling.cpp
   - test/test_mb8877_timing.cpp
   - test/test_mb8877_compatibility.cpp

2. 修正されたファイル:
   - src/vm/mb8877.cpp（置き換え後）
   - src/vm/mb8877.h（置き換え後）

3. レポートファイル:
   - docs/reports/integration-test-results.md

## レポート形式

以下の項目を含めること：
- テスト実施日時
- 完了したテスト項目の詳細
- 置き換えテスト結果
- 発見された問題と修正内容
- 性能測定結果
- 各エミュレータでの動作状況
- 残存する問題と対策
- Phase 3への推奨事項

## 作業完了時の対応

1. 全テストコードをコミット
2. 修正されたmb8877.cpp/hをコミット
3. レポートファイルを作成
4. 作業内容をコミット（コミットメッセージ: "統合テスト: mb8877.cpp置き換え完了"）
5. ユーザーに作業完了を報告
6. 実用レベルでの動作確認結果を明記

## 注意事項

- 元のmb8877.cpp/hは必ずバックアップを取ること
- ビルドエラーが発生した場合は詳細なログを取ること
- 動作不具合は再現手順とともに記録すること
- 性能劣化が発生した場合は原因を特定すること
- 各エミュレータで一貫した動作をすることを確認すること
- 問題解決が困難な場合は元のファイルに戻せるようにしておくこと
