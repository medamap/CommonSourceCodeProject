# MB8877構造調査エージェント指示書

## エージェント名
InvestigationAgent-MB8877

## 作業目的
mb8877.cpp および mb8877.h の構造を詳細に調査し、wd_fdc.cpp への移植に必要な情報を収集する

## 調査項目

### 1. パブリックメソッドの一覧
- mb8877.h から全てのパブリックメソッドを抽出
- 各メソッドの引数と戻り値
- メソッドの役割と使用目的

### 2. パブリックフィールドの一覧
- mb8877.h から全てのパブリックフィールドを抽出
- フィールドの型と初期値
- フィールドの役割

### 3. イベント駆動の仕組み
- イベント登録/削除の方法
- イベントハンドラの実装方式
- タイミング管理の仕組み

### 4. 外部依存関係
- 他のクラスやモジュールとの関係
- インクルードしているヘッダファイル
- 使用している外部関数やマクロ

### 5. ディスクI/O処理
- ディスクとのやり取りの実装方法
- セクタ読み書きの処理フロー
- エラーハンドリング

## 作業手順

1. src/vm/mb8877.h を読み込み、クラス定義を解析
2. src/vm/mb8877.cpp を読み込み、実装の詳細を解析
3. 調査結果を整理し、レポートにまとめる

## 成果物

レポートファイル: `docs/reports/mb8877-structure-analysis.md`

## レポート形式

以下の項目を含めること：
- 調査日時
- ファイルの概要（行数、ファイルサイズなど）
- 各調査項目の詳細な結果
- 移植時の注意点や課題
- 推奨される次のステップ

## 作業完了時の対応

1. レポートファイルを作成し、調査結果を記載
2. 作業内容をコミット（コミットメッセージ: "調査: mb8877.cpp/hの構造解析完了"）
3. ユーザーに作業完了を報告
4. レポートファイルの作成完了を明記

## 注意事項

- コードの著作権やライセンスに関する記述があれば特に注意して記録すること
- イベント駆動の仕組みとタイミング処理について特に詳細に調査すること
- wd_fdc.cpp との違いを意識しながら調査を進めること
