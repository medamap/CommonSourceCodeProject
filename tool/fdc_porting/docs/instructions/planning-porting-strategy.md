# 移植計画策定エージェント指示書

## エージェント名
PlanningAgent-PortingStrategy

## 作業目的
MB8877とwd_fdcの調査結果を基に、具体的で実行可能な移植計画を策定する

## 前提情報
- MB8877構造解析完了（docs/reports/mb8877-structure-analysis.md）
- wd_fdc構造解析完了（docs/reports/wd-fdc-structure-analysis.md）
- wd_fdcは3段階移植アプローチが推奨されている
- シーケンシャルシンキングツールの活用を推奨

## 調査・検討項目

### 1. 技術的実現可能性の詳細評価
- mb8877_deviceクラスの設計詳細
- wd_fdc_device_baseからの継承方法
- インターフェース互換性の確保方法
- イベント駆動からステートマシンへの変換パターン

### 2. 段階的実装計画の詳細化
- Phase 1: 基本互換レイヤー
  - 必要なクラス・メソッドの特定
  - スタブ実装の範囲
  - 動作確認方法
- Phase 2: 特殊機能の実装
  - MB89311拡張機能の実装方法
  - 特殊ディスク対応の実装方法
  - ノイズ再生機能の統合方法
- Phase 3: 最適化と検証
  - パフォーマンス測定項目
  - 互換性検証項目
  - テスト戦略

### 3. リスク分析と対策
- 技術的リスクの特定
- スケジュールリスクの評価
- 互換性リスクの評価
- 各リスクへの対策案

### 4. 実装順序とタスク分割
- 各フェーズの詳細タスクリスト
- タスク間の依存関係
- エージェントへの作業割り当て案
- 推定作業時間

### 5. テスト戦略
- 単体テストの設計
- 統合テストの設計
- 互換性テストの設計
- リグレッションテストの計画

## 作業手順

1. 両調査レポートを詳細に分析
2. シーケンシャルシンキングツールを使用して段階的に計画を策定
3. 各フェーズの技術的詳細を検討
4. リスクと対策を洗い出す
5. 実装可能な詳細計画を作成

## 成果物

1. レポートファイル: `docs/reports/porting-strategy-plan.md`
2. 技術検証用サンプルコード（必要に応じて）

## レポート形式

以下の項目を含めること：
- 策定日時
- エグゼクティブサマリー
- 技術的アプローチの詳細
- 3フェーズの詳細実装計画
- リスク分析と対策
- タスク分割とスケジュール案
- テスト戦略
- 次のステップへの推奨事項

## 作業完了時の対応

1. レポートファイルを作成し、計画を記載
2. 作業内容をコミット（コミットメッセージ: "計画: MB8877からwd_fdcへの移植戦略策定完了"）
3. ユーザーに作業完了を報告
4. レポートファイルの作成完了を明記

## 注意事項

- 実装の実現可能性を重視すること
- 段階的アプローチで早期に動作確認できる計画とすること
- CommonSourceCodeProjectの既存構造への影響を最小限にすること
- ライセンス問題の完全な解決を確認すること
- 将来の保守性を考慮した設計とすること
