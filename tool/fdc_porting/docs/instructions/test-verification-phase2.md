# Phase 2 テスト検証エージェント指示書

## エージェント名
TestAgent-Verification

## 作業目的
Phase 1で実装したMB8877互換レイヤーの動作を検証し、実機での互換性を確認する

## 前提情報
- Phase 1でmb8877_compat.h/cppの完全実装が完了
- 全コマンド（Type I-IV）およびMB89311拡張が実装済み
- MAMEのwd_fdcステートマシンアプローチを採用
- 実機でのテストは未実施

## 検証項目

### 1. テストフレームワークの構築
- 単体テスト環境の構築
- モックディスクイメージの作成
- テストハーネスの実装
- 自動テストスクリプトの作成

### 2. 基本動作テスト
#### 2.1 レジスタアクセステスト
- 各レジスタの読み書き動作
- ステータスレジスタのビット更新
- MB8866/MB8876の反転バス動作

#### 2.2 Type I コマンドテスト
- Restore: トラック0への移動確認
- Seek: 任意トラックへの移動（0〜79）
- Step/Step In/Step Out: 1トラック移動
- Verify機能の動作確認

#### 2.3 Type II コマンドテスト
- Read Sector: 単一/複数セクタ読み込み
- Write Sector: 単一/複数セクタ書き込み
- データ整合性の確認
- CRCエラー検出

#### 2.4 Type III コマンドテスト
- Read Address: IDフィールド読み込み
- Read Track: トラック全体読み込み
- Write Track: フォーマット動作

#### 2.5 Type IV コマンドテスト
- Force Interrupt: 各種条件での割り込み

### 3. エラー処理テスト
- ディスク未挿入時の動作
- ライトプロテクト検出
- セクタ未検出（RNF）
- データロスト処理
- CRCエラー処理

### 4. タイミング検証
- シーク時間の測定
- DRQタイミングの確認
- インデックスホール検出
- セクタ間隔の確認

### 5. 特殊ディスク対応テスト
- FM7特殊ディスク（RIGLAS等）
- X1特殊ディスク（Batten Tanuki）
- 各種フォーマットの読み込み

### 6. 互換性テスト
- 元のmb8877.cppとの動作比較
- 既存エミュレータでの動作確認
- 実機録音データとの比較（可能なら）

## 作業手順

1. テスト環境の構築
   - test/ディレクトリの作成
   - テストフレームワークの選定と設定
   - ビルド環境の調整

2. テストコードの実装
   - 単体テストの作成
   - 統合テストの作成
   - パフォーマンステストの作成

3. テスト実行と結果収集
   - 自動テストの実行
   - 結果の記録と分析
   - 問題点の特定

4. 不具合修正
   - 発見された問題の修正
   - 再テストの実施
   - 修正内容の文書化

以下の項目を含めること：
- テスト実施日時

- 発見された問題と対策

## 作業完了時の対応

1. テストコードとテスト結果をコミット
2. レポートファイルを作成
3. 作業内容をコミット（コミットメッセージ: "テスト: Phase 2 動作検証完了"）
4. ユーザーに作業完了を報告
5. 修正が必要な項目を明記

## 注意事項

- テストは網羅的に実施し、エッジケースも含めること
- パフォーマンスへの影響を測定すること
- 元のmb8877.cppとの互換性を最優先すること
- テスト結果は再現可能な形で記録すること
- 不具合は詳細な再現手順とともに報告すること
