# Phase 1 基本互換レイヤー実装エージェント指示書

## エージェント名
ImpAgent-BasicWrapper

## 作業目的
mb8877_deviceラッパークラスの基本構造を実装し、標準的なFDC操作の互換性を確立する

## 前提情報
- 移植戦略計画書完了（docs/reports/porting-strategy-plan.md）
- MAMEのwd_fdcソースはtemp/mame-wd_fdc/に配置済み
- 2-3週間での基本動作確認を目標
- 既存のMB8877インターフェースを完全に維持

## 実装項目

### 1. プロジェクト準備
- src/vm/mb8877_compat.h/cppファイルの作成
- 必要なMAMEヘッダファイルの確認と調整
- ビルド環境の設定確認

### 2. mb8877_deviceクラスの基本実装
```cpp
class mb8877_device : public wd_fdc_analog_device_base {
    // 既存MB8877と同一のパブリックインターフェース
    // 内部でwd_fdcの機能を活用
};
```

### 3. I/Oインターフェース実装
- write_io8/read_io8メソッド
  - アドレス0: コマンド/ステータス
  - アドレス1: トラックレジスタ
  - アドレス2: セクタレジスタ  
  - アドレス3: データレジスタ
- write_dma_io8/read_dma_io8メソッド
- write_signal/read_signalメソッド

### 4. レジスタ管理層
- MB8877形式のレジスタ配置をwd_fdc形式に変換
- ステータスレジスタのビット配置変換
- コマンドレジスタの解釈と変換

### 5. ディスク管理インターフェース
- DISK配列からfloppy_image_deviceへの変換層
- open_disk/close_diskメソッドの実装
- is_disk_inserted/is_disk_protectedの実装
- ドライブ選択ロジック（drvreg/sidereg）

### 6. 基本的な状態管理
- initialize/release/resetメソッド
- update_configメソッド
- process_stateメソッド（ステート保存/読み込み）

### 7. スタブ実装
- 以下の機能は空実装で配置：
  - MB89311拡張コマンド
  - 特殊ディスク対応
  - ノイズ再生機能

## 作業手順

1. mb8877_compat.h/cppを作成し、クラス定義を実装
2. 基本的なI/Oメソッドを実装
3. レジスタアクセス変換層を実装
4. ディスク管理インターフェースを実装
5. 単体テストを作成し、基本動作を確認
6. 既存のmb8877.cppとの互換性を検証

## テスト項目

1. **レジスタアクセステスト**
   - 各レジスタの読み書き
   - ステータスレジスタの正確性

2. **基本コマンドテスト**
   - Restore（トラック0へ移動）
   - Seek（指定トラックへ移動）
   - Read Sector（セクタ読み込み）
   - Write Sector（セクタ書き込み）

3. **ディスク管理テスト**
   - ディスク挿入/取り出し
   - ライトプロテクト検出
   - ドライブ切り替え

## レポート形式

以下の項目を含めること：
- 実装完了日時
- 実装した機能の一覧

- 既知の問題と制限事項

## 作業完了時の対応

1. 実装ファイルとテストコードをコミット
2. レポートファイルを作成
3. 作業内容をコミット（コミットメッセージ: "実装: Phase 1 基本互換レイヤー完了"）
4. ユーザーに作業完了を報告
5. テスト結果と動作確認状況を明記

## 注意事項

- 既存のmb8877.hのパブリックインターフェースを厳密に維持すること
- wd_fdcのライセンス（BSD-3-Clause）を尊重すること
- 実装の各段階で動作確認を行い、問題を早期に発見すること
- 不明な点は元のmb8877.cppの実装を参照すること
- Phase 2以降の拡張を考慮した設計とすること
