# 重要な開発ガイドライン

## コアソースコードの保護

### 基本原則

**src配下のコアソースコードは原則として変更禁止です。**

#### 保護対象（コア部分）
以下のディレクトリ/ファイルは複数のOS環境で共有されるコア部分です：
- `src/*.cpp`, `src/*.h`（トップレベルのファイル）
- `src/vm/` - 仮想マシン実装
- `src/res/` - リソース定義
- `src/menu/` - 共通メニューシステム

#### プラットフォーム固有部分（変更可能）
- `src/Xcode/` - macOS/iOS固有実装
- `src/Android/` - Android固有実装  
- `src/win32/` - Windows固有実装

### コアソース修正時のルール

どうしてもコアソースの修正が必要な場合は、以下のルールに従ってください：

#### 1. プリプロセッサによる条件分岐を使用

```cpp
#ifdef _XCODE
    // Xcode固有の処理
#else
    // 既存の処理
#endif
```

#### 2. 修正箇所には必ずコメントを記載

```cpp
// Medamap and Claude: Metal描画のためRGB565バッファアクセスを追加
#ifdef _XCODE
    uint16_t* get_screen_buffer_rgb565() { return screen_buffer_565; }
#endif
```

#### 3. 署名フォーマット

```
// Medamap and Claude: [修正理由を明確に記載]
```

### 修正例

#### 良い例
```cpp
// src/emu.cpp
void EMU::update_screen() {
    // 既存のコード...
    
    // Medamap and Claude: iOSでのバックグラウンド処理対応
    #ifdef _IOS
    if (is_background) {
        return;  // バックグラウンドでは描画をスキップ
    }
    #endif
    
    // 既存のコード続き...
}
```

#### 悪い例
```cpp
// 署名なし、理由不明な修正
#ifdef _XCODE
    do_something();
#endif

// 既存コードを直接変更
void EMU::initialize() {
    // screen_width = 640;  // コメントアウトだけ
    screen_width = 1024;    // Xcodeでは1024にしたい
}
```

### チェックリスト

コアソースを修正する前に確認：

- [ ] プラットフォーム固有ディレクトリで解決できないか？
- [ ] 既存のインターフェースで対応できないか？
- [ ] 他のプラットフォームへの影響はないか？
- [ ] プリプロセッサ条件は適切か？
- [ ] コメントと署名を記載したか？

### 影響範囲の確認

修正前に必ず確認：
1. Windows版のビルドが壊れていないか
2. Android版のビルドが壊れていないか
3. 他の機種（X1以外）への影響はないか
