# Development Environment

This repository is an Android port of the upstream Common Source Code Project.

## Recommended Setup

- Install Android Studio.
- Use JDK 17 for Gradle.
- Keep `androidstudio/local.properties` local and untracked.
- The original wiki setup flow uses a custom Android Studio device profile and
  recommends Gradle JDK 17.

## Build Notes

- See [Build process](build-process.md) for the normal build flow.
- The wiki also documents a more manual Android Studio setup flow and device
  configuration steps.
