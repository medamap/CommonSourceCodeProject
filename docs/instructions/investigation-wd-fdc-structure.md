# WD_FDC構造調査エージェント指示書

## エージェント名
InvestigationAgent-WD_FDC

## 作業目的
MAMEプロジェクトのwd_fdc.cppおよび関連ファイルの構造を詳細に調査し、mb8877.cppからの移植に必要な情報を収集する

## 前提情報
- MB8877の構造解析は完了済み（docs/reports/mb8877-structure-analysis.md参照）
- MB8877はイベント駆動、wd_fdcはステートマシン駆動という違いがある
- MAMEの最新版からwd_fdc関連ファイルを取得する必要がある

## 調査項目

### 1. wd_fdc.cppの取得と基本構造
- MAMEの公式リポジトリから最新のwd_fdc.cpp/hを取得
- クラス階層と継承関係の把握
- ファイルサイズと構造の概要

### 2. パブリックインターフェースの比較
- MB8877と共通のメソッドの有無
- 対応するメソッドのマッピング
- 新規実装が必要なメソッドの特定

### 3. ステートマシンの仕組み
- ステート定義と遷移条件
- タイミング管理の方法
- MB8877のイベント駆動との対応関係

### 4. ディスクI/O実装の差異
- セクタ読み書きの実装方法
- エラーハンドリングの方式
- CRCチェックとデータ整合性

### 5. 特殊機能の対応状況
- MB8877が持つ特殊ディスク対応の可否
- MB89311拡張モードの実装可能性
- ノイズ再生機能の統合方法

## 作業手順

1. MAMEリポジトリからwd_fdc関連ファイルを取得
   - https://github.com/mamedev/mame/blob/master/src/devices/machine/wd_fdc.cpp
   - https://github.com/mamedev/mame/blob/master/src/devices/machine/wd_fdc.h
   - 関連する依存ファイルも確認

2. 取得したファイルをtempディレクトリに保存

3. ファイルの構造を解析し、MB8877との対応を調査

4. 移植に必要な変更点をリストアップ

5. 調査結果をレポートにまとめる

## 成果物

1. レポートファイル: `docs/reports/wd-fdc-structure-analysis.md`
2. 取得したMAMEのwd_fdc関連ファイル（tempディレクトリ）

## レポート形式

以下の項目を含めること：
- 調査日時
- 取得したファイルのバージョン情報
- ファイルの概要（行数、ファイルサイズなど）
- MB8877との機能対応表
- ステートマシンとイベント駆動の対応関係
- 移植時の技術的課題
- 推奨される移植アプローチ

## 作業完了時の対応

1. レポートファイルを作成し、調査結果を記載
2. 取得したMAMEファイルを適切に保存
3. 作業内容をコミット（コミットメッセージ: "調査: wd_fdc.cpp/hの構造解析完了"）
4. ユーザーに作業完了を報告
5. レポートファイルの作成完了を明記

## 注意事項

- MAMEのライセンス（BSD-3-Clause）との互換性を確認すること
- wd_fdcのコードはMAMEのdeviceフレームワークに依存している点に注意
- MB8877の特殊機能がwd_fdcでどこまで実現可能か重点的に調査すること
- ステートマシンとイベント駆動の変換方法について具体的な提案を含めること
