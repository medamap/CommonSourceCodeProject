# Phase 1 完成実装エージェント指示書

## エージェント名
ImpAgent-Phase1-Completion

## 作業目的
mb8877_compatの基本構造に対して、MAMEのwd_fdcを統合し、実際に動作するFDCエミュレーションを完成させる

## 前提情報
- mb8877_compat.h/cppの基本構造は実装済み
- 現在はスタブ実装で、実際のFDC動作は未実装
- MAMEのwd_fdcソースはtemp/mame-wd_fdc/に配置済み
- 元のmb8877.cpp/hは参照実装として利用可能

## 実装項目

### 1. MAMEのwd_fdc統合準備
- temp/mame-wd_fdc/からの必要なファイルの特定
- ライセンス互換性の確認（BSD-3-Clause）
- 必要最小限のMAME依存関係の抽出

### 2. wd_fdc_analog_device_base継承の実装
```cpp
// 現在のスタブから実際の継承に変更
class mb8877_device : public wd_fdc_analog_device_base {
    // 既存のインターフェースを維持しながら
    // wd_fdcの機能を活用
};
```

### 3. レジスタ変換層の実装
- MB8877ステータスレジスタ → wd_fdcステータスレジスタ
- コマンドレジスタの解釈と変換
- トラック/セクタ/データレジスタのマッピング

### 4. 基本コマンドの実装
#### Type I コマンド（Restore/Seek/Step）
- cmd_restore() - トラック0へのリストア
- cmd_seek() - 指定トラックへのシーク  
- cmd_step() - ステップイン/アウト

#### Type II コマンド（Read/Write Sector）
- cmd_read_sector() - セクタ読み込み
- cmd_write_sector() - セクタ書き込み

#### Type III コマンド（Read Address/Track）
- cmd_read_address() - アドレスマーク読み込み
- cmd_read_track() - トラック読み込み
- cmd_write_track() - トラック書き込み

#### Type IV コマンド（Force Interrupt）
- cmd_force_interrupt() - 強制割り込み

### 5. ディスク管理層の実装
- DISKクラス → floppy_image_device変換
- セクタデータアクセスの実装
- ディスクフォーマット情報の変換

### 6. タイミング管理の実装
- MB8877のイベントタイミング → wd_fdcの時間管理
- DRQタイミングの実装
- シークタイミングの計算

### 7. 割り込み/DRQ/RDY信号の実装
- set_context_irq/drq/rdyで設定されたデバイスへの通知
- ステータス変化時の適切な信号出力

## 実装手順

1. MAMEのwd_fdc関連ファイルから必要な部分を抽出
2. mb8877_compat.cppのスタブ実装を順次置き換え
3. 各コマンドタイプごとに実装とテスト
4. レジスタアクセスの動作確認
5. 簡単なディスクイメージでの読み書きテスト

## テスト項目

1. **基本動作テスト**
   - Restoreコマンドでトラック0へ移動
   - Seekコマンドで任意トラックへ移動
   - ステータスレジスタの正しい更新

2. **読み書きテスト**
   - 単一セクタの読み込み
   - 単一セクタの書き込み
   - 読み書き後のデータ整合性確認

3. **エラー処理テスト**
   - ディスク未挿入時の動作
   - ライトプロテクト時の書き込み
   - 存在しないセクタへのアクセス

## 成果物

1. 更新ファイル:

4. ユーザーに作業完了を報告
5. 基本的なFDC動作が確認できたことを明記

## 注意事項

- MAMEのコードは最小限の利用に留め、ライセンスを明記すること
- 元のmb8877.cppの動作を参考に、互換性を保つこと
- エラー処理は元の実装と同等レベルを維持すること
- パフォーマンスよりも正確性を優先すること
- 不明な点は保守的な実装を選択すること
